- Репликация — процесс самоудвоения молекулы ДНК.
- Происходит в **S-период интерфазы**.
- Репликация идёт по **полуконсервативному** механизму.
- Это означает, что каждая дочерняя молекула содержит одну старую и одну новую цепь.
- Цепи материнской ДНК расходятся (разрываются водородные связи) с помощью фермента **хеликазы**.
- Образуется **репликационная вилка**.
- Достраивание новых цепей ведёт фермент **ДНК-полимераза**.
- Новые нуклеотиды присоединяются по **принципу комплементарности**.
- ДНК-полимераза синтезирует цепь только в направлении 5′→3′.
- Одна цепь (**лидирующая**) синтезируется непрерывно.
- Другая цепь (**отстающая**) синтезируется фрагментами — **фрагментами Оказаки**.
- Фрагменты Оказаки сшиваются ферментом **ДНК-лигазой**.

**Биологический смысл репликации:**

- Обеспечивает точное удвоение наследственной информации перед делением.
- Гарантирует передачу одинаковой информации дочерним клеткам.
- Лежит в основе постоянства генетического материала из поколения в поколение.
