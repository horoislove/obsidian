| **Признак**              | **Прокариоты**                              | **Эукариоты**                                            |
| ------------------------ | ------------------------------------------- | -------------------------------------------------------- |
| **Примеры**              | ==бактерии археи==                          | ==растения животные грибы==                              |
| **Ядро**                 | Нет оформленного ядра.  <br>ДНК в нуклеоиде | Есть, окружено двойной мембраной                         |
| **Размер**               | 1–10 мкм                                    | 10–100 мкм                                               |
| **Мембранные органеллы** | Нет (митохондрий, ЭР, Гольджи нет)          | Есть (митохондрии, ЭР, Гольджи, лизосомы)                |
| **Рибосомы**             | Есть, но меньше — 70S                       | Есть, крупнее — 80S                                      |
| **ДНК**                  | Кольцевая, одна молекула, без гистонов      | Линейная, несколько хромосом, с гистонами                |
| **Клеточная стенка**     | Есть (пептидогликан у бактерий)             | У растений (целлюлоза), грибов (хитин), у животных — нет |
| **Цитоскелет**           | Нет                                         | Есть                                                     |
| **Деление**              | Бинарное деление (простое)                  | Митоз / мейоз                                            |

Главный критерий различия — ==наличие== оформленного ==ядра==. У **прокариот** ДНК просто лежит в цитоплазме в зоне, называемой ==нуклеоидом==. У **эукариот** ядро ==отделено== двойной мембраной.

Второй ключевой момент — ==мембранные органеллы==. У **прокариот** их ==нет== вообще. Поэтому бактерии дышат прямо через плазматическую мембрану, а не через митохондрии.

Рибосомы есть и у **Прокариотов** и **Эукариотов**.
