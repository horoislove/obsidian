## 1. Генетический код и его свойства

- Генетический код — система записи наследственной информации о последовательности аминокислот в белке с помощью последовательности нуклеотидов.
- Единица кода — **триплет (кодон)**, состоящий из трёх нуклеотидов.
- Один триплет кодирует одну аминокислоту.
- Всего возможно **64 триплета** (4³).
- Из них **61 кодон** кодирует аминокислоты.
- **3 триплета** являются стоп-кодонами (терминирующими): УАА, УАГ, УГА.
- Стоп-кодоны не кодируют аминокислот и сигналят об окончании синтеза белка.
- Кодон **АУГ** является стартовым (инициирующим) и кодирует метионин.

**Свойства генетического кода:**

- **Триплетность** — одну аминокислоту кодируют три нуклеотида.
- **Однозначность (специфичность)** — каждый триплет кодирует только одну определённую аминокислоту.
- **Вырожденность (избыточность)** — одна аминокислота может кодироваться несколькими триплетами.
- **Неперекрываемость** — один нуклеотид входит в состав только одного триплета.
- **Непрерывность (отсутствие запятых)** — между триплетами нет разделительных знаков.
- **Универсальность** — код единый почти для всех живых организмов.
- **Колинеарность** — последовательность триплетов соответствует последовательности аминокислот в белке.
## 2. Уровни организации и структуры ДНК

- ДНК — биополимер, мономерами которого являются **нуклеотиды**.
- Каждый нуклеотид состоит из азотистого основания, дезоксирибозы и остатка фосфорной кислоты.
- Азотистые основания: аденин (А), тимин (Т), гуанин (Г), цитозин (Ц).

**Первичная структура:**

- Это последовательность нуклеотидов в одной цепи, соединённых ковалентными связями.

**Вторичная структура:**

- Это **двойная спираль** из двух полинуклеотидных цепей (модель Уотсона и Крика, 1953).
- Цепи соединены **водородными связями** между азотистыми основаниями.
- Основания соединяются по **принципу комплементарности**: А–Т (две связи), Г–Ц (три связи).
- Цепи **антипараллельны** (направлены противоположно: 5′→3′ и 3′→5′).
- Правило Чаргаффа: количество А = Т, а Г = Ц.
  
**Третичная структура:**

- Это спирализация и упаковка ДНК с участием белков.
- ДНК наматывается на белки-**гистоны**, образуя **нуклеосомы**.
- Нуклеосомы образуют нить хроматина.
- Дальнейшая спирализация приводит к образованию хромосомы.

## 3. Эухроматин, гетерохроматин, хромосомы, плоидность

### Хроматин

- **Эухроматин** — слабо спирализованный (деконденсированный) хроматин.
- Эухроматин транскрипционно активен (с него считывается информация).
- **Гетерохроматин** — сильно спирализованный (конденсированный) хроматин.
- Гетерохроматин транскрипционно неактивен.

### Хромосомы

- Хромосома — максимально спирализованная ДНК с белками, видимая при делении клетки.
- Хромосома состоит из двух **хроматид**, соединённых **центромерой**.
- Центромера делит хромосому на **плечи**.
- По расположению центромеры различают равноплечие, неравноплечие и палочковидные хромосомы.
- Концевые участки хромосом называются **теломерами**.
- **Гомологичные хромосомы** — парные, одинаковые по размеру, форме и набору генов.

### Плоидность

- Плоидность — число наборов хромосом в клетке.
- **Гаплоидный набор (n)** — одинарный набор хромосом (в гаметах).
- **Диплоидный набор (2n)** — двойной набор хромосом (в соматических клетках).
- **Полиплоидия** — наличие более двух наборов (3n, 4n и т. д.).
- **Кариотип** — совокупность признаков хромосомного набора (число, форма, размер).
